# pi-system-monitor

A small macOS Pi extension that shows CPU, memory, free disk space, and optional temperature in a compact footer. It also opens interactive Pi sessions in a clean alternate screen.

Temperature is shown when `macmon` or `osx-cpu-temp` is already available. If neither is installed, the other metrics continue normally.

## Install

```bash
pi install https://github.com/dantetekanem/pi-system-monitor.git
```

Restart Pi after installation.
